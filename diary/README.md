# ไดอารี่ (ส่วนตัว)

โฟลเดอร์นี้ **ไม่ถูก push ขึ้น GitHub** — `.gitignore` กันไว้แล้ว
เพราะ repo เป็น public ถ้าเผลอ commit ใครมีลิงก์ก็อ่านได้

เขียนเท่าที่อยากเขียน ไม่ต้องทุกวัน

## วิธีใช้

สร้างไฟล์ใหม่ใน `entries/` ตั้งชื่อเป็นวันที่:

```
diary/entries/2026-07-30.md
```

ก็อป `TEMPLATE.md` ไปใช้ได้ หรือเขียนสดๆ ก็ได้ ไม่มีกฎ

## ทำไมตั้งชื่อไฟล์เป็น YYYY-MM-DD

เรียงตามวันเองอัตโนมัติเวลา `ls` และหาไฟล์ง่ายตอนมีเยอะๆ

## ถ้าวันหลังอยากให้บางวันขึ้นเว็บ

ย้ายไฟล์นั้นไปไว้ที่ `pages/` แล้วทำเป็น HTML แยก — ตั้งใจแยก
โฟลเดอร์ไว้แบบนี้เพื่อไม่ให้ของส่วนตัวหลุดขึ้นเว็บโดยไม่ตั้งใจ
